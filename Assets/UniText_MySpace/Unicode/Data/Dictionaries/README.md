# ICU word segmentation dictionaries

Unmodified sources from [ICU 78.3](https://github.com/unicode-org/icu/tree/release-78.3/icu4c/source/data/brkitr/dictionaries):
`icu4c/source/data/brkitr/dictionaries`.

- `laodict.txt` → `UnicodeScript.Lao`
- `khmerdict.txt` → `UnicodeScript.Khmer`
- `burmesedict.txt` → `UnicodeScript.Myanmar`
- `cjdict.txt` → `UnicodeScript.Han`

`cjdict.txt` includes tab-separated costs accepted by the UniText dictionary compiler.
